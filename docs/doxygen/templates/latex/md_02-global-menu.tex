The menu lies on the left side of the interface. For each option or item in the global menu, the tag menu or the tile menu, the icon will appear white if the option is not selected or used, and grey if it is selected. To select a menu item, you have to click on it. If you entered an option and do not wish anymore to go further with it, clicking on the grey icon will exit it.

\doxysubsubsection*{Filter with keywords}



Type keywords in the research bar, they will be matched with a list of keywords extracted from the meta-\/data of the tiles. Auto-\/completion is enabled for this ﬁeld. The “\&” can be used to combine several keywords. Upon hitting “\+Enter”, the tiles corresponding to the keywords are moved to the top, and little stickers appears on their right side to show to which keyword(s) they ﬁt. The legend for the colors is shown at the top right of the interface.

\doxysubsubsection*{Clear all selections}



Click on the icon clear all the selections on the session.

\doxysubsubsection*{Show next tiles}



Click on the icon will reorganize the grid and show the next page of tiles below.

\doxysubsubsection*{Rotate tiles}



Shows little rotation icons for each tile (only activated with a touch table or a tablet if it is detected).

\doxysubsubsection*{Refresh tiles}



Refresh all the nodes with their original sources.

\doxysubsubsection*{Menu for tags}



Tags are representation of metadata of each tile.

You can sort, select, hide or delete tiles with them in this menu. And you manage them :\+ add or remove tags

See below in Tags menu section.

\doxysubsubsection*{Menu for actions on each Tile\+Sets}



Actions are speciﬁc functions programmed with each tilesets.

Action functions are programmed in the case python script for CONNECTION Tile\+Sets only.

You can programm change of the source and with the ﬁrst button it will force Tiled\+Viz to update

the list of nodes and the metadata (title, tags, ...).
