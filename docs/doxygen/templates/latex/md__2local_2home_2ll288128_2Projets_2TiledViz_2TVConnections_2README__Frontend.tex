TVConnection is launched from tvconnections.\+sh in connection docker to manage password to Frontend of HPC machine.

It creates VNC secure flux with TVSecure in secure host and a communication socket with the client browser through Flask server with action.\+json list of actions.

It launchs the script job.

Launch Tile\+Server by hand on Frontend with logging :\+ ipython3 .tiledviz/\+\+Tile\+Server.\+py --debug 2\texorpdfstring{$>$}{>}\&1 \texorpdfstring{$\vert$}{|}tee -\/a /\+tmp/\+\+Tile\+Server\+\_\+ One can switch DEBUG to increase verbosity and control message with clients.

Generic functions for all cases :\+ "{}tile\+Num"{} is the number of a tile in a Tile\+Set and "{}tile\+Id"{} is a string for its Id given by container\+Id(tile\+Num+1).
