The interface of the no\+VNC client consists of a single \doxylink{classRFB}{RFB} object that is instantiated once per connection.

\doxysection*{\doxylink{classRFB}{RFB}}

The {\ttfamily \doxylink{classRFB}{RFB}} object represents a single connection to a VNC server. It communicates using a Web\+Socket that must provide a standard \doxylink{classRFB}{RFB} protocol stream.

\doxysubsubsection*{bell}

The {\ttfamily bell} event is fired when the server has requested an audible bell.

\doxysubsubsection*{capabilities}

The {\ttfamily capabilities} event is fired whenever an entry is added or removed from {\ttfamily RFB.\+capabilities}. The {\ttfamily detail} property is an {\ttfamily Object} with the property {\ttfamily capabilities} containing the new value of {\ttfamily RFB.\+capabilities}.

\doxysubsubsection*{clippingviewport}

The {\ttfamily clippingviewport} event is fired whenever {\ttfamily RFB.\+clipping\+Viewport} changes between {\ttfamily true} and {\ttfamily false}. The {\ttfamily detail} property is a {\ttfamily boolean} with the new value of {\ttfamily RFB.\+clipping\+Viewport}.

\doxysubsubsection*{clipboard}

The {\ttfamily clipboard} event is fired when the server has sent clipboard data. The {\ttfamily detail} property is an {\ttfamily Object} containing the property {\ttfamily text} which is a {\ttfamily DOMString} with the clipboard data.

\doxysubsubsection*{credentialsrequired}

The {\ttfamily credentialsrequired} event is fired when the server requests more credentials than were specified to \`{}\+RFB()\`{}{\ttfamily \doxylink{classRFB}{RFB()}}. The {\ttfamily detail} property is an {\ttfamily Object} containing the property {\ttfamily types} which is an {\ttfamily Array} of {\ttfamily DOMString} listing the credentials that are required.

\doxysubsubsection*{connect}

The {\ttfamily connect} event is fired after all the handshaking with the server is completed and the connection is fully established. After this event the {\ttfamily \doxylink{classRFB}{RFB}} object is ready to recieve graphics updates and to send input.

\doxysubsubsection*{desktopname}

The {\ttfamily desktopname} event is fired when the name of the remote desktop changes. The {\ttfamily detail} property is an {\ttfamily Object} with the property {\ttfamily name} which is a {\ttfamily DOMString} specifying the new name.

\doxysubsubsection*{disconnect}

The {\ttfamily disconnect} event is fired when the connection has been terminated. The {\ttfamily detail} property is an {\ttfamily Object} that contains the property {\ttfamily clean}. {\ttfamily clean} is a {\ttfamily boolean} indicating if the termination was clean or not. In the event of an unexpected termination or an error {\ttfamily clean} will be set to false.

\doxysubsubsection*{securityfailure}

The {\ttfamily securityfailure} event is fired when the handshaking process with the server fails during the security negotiation step. The {\ttfamily detail} property is an {\ttfamily Object} containing the following properties:\+


\begin{DoxyTable}{3}{}{}{1}
\SetCell{c,bg=\tableheadbgcolor,font=\bfseries}Property  &\SetCell{c,bg=\tableheadbgcolor,font=\bfseries}Type  &\SetCell{c,bg=\tableheadbgcolor,font=\bfseries}Description  \\
{\ttfamily status}  &{\ttfamily long}  &The failure status code  \\
{\ttfamily reason}  &{\ttfamily DOMString}  &The {\bfseries{optional}} reason for the failure  \\
\end{DoxyTable}


The property {\ttfamily status} corresponds to the \href{https://github.com/rfbproto/rfbproto/blob/master/rfbproto.rst\#securityresult}{\texttt{Security\+Result}} status code in cases of failure. A status of zero will not be sent in this event since that indicates a successful security handshaking process. The optional property {\ttfamily reason} is provided by the server and thus the language of the string is not known. However most servers will probably send English strings. The server can choose to not send a reason and in these cases the {\ttfamily reason} property will be omitted.

\doxysubsubsection*{serververification}

The {\ttfamily serververification} event is fired when the server provides information that allows the user to verify that it is the correct server and protect against a man-\/in-\/the-\/middle attack. The {\ttfamily detail} property is an {\ttfamily Object} containing the property {\ttfamily type} which is a {\ttfamily DOMString} specifying which type of information the server has provided. Other properties are also available, depending on the value of {\ttfamily type}:\+

{\ttfamily "{}RSA"{}}
\begin{DoxyItemize}
\item The server identity is verified using just a RSA key. The property {\ttfamily publickey} is a {\ttfamily Uint8\+Array} containing the public key in a unsigned big endian representation.
\end{DoxyItemize}
