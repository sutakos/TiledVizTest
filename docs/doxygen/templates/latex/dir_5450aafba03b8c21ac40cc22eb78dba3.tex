\doxysubsubsection*{Description}

no\+VNC is both a HTML VNC client Java\+Script library and an application built on top of that library. no\+VNC runs well in any modern browser including mobile browsers (i\+OS and Android).

Many companies, projects and products have integrated no\+VNC including \href{http://www.openstack.org}{\texttt{Open\+Stack}}, \href{http://opennebula.org/}{\texttt{Open\+Nebula}}, \href{http://libvncserver.sourceforge.net}{\texttt{Lib\+VNCServer}}, and \href{https://cendio.com/thinlinc}{\texttt{Thin\+Linc}}. See \href{https://github.com/novnc/noVNC/wiki/Projects-and-companies-using-noVNC}{\texttt{the Projects and companies wiki page}} for a more complete list with additional info and links.

\doxysubsubsection*{Features}


\begin{DoxyItemize}
\item Supports all modern browsers including mobile (i\+OS, Android)
\item Supported authentication methods:\+ none, classical VNC, Real\+VNC\textquotesingle{}s RSA-\/\+AES, Tight, Ve\+NCrypt Plain, XVP, Apple\textquotesingle{}s Diffie-\/\+Hellman, Ultra\+VNC\textquotesingle{}s MSLogon\+II
\item Supported VNC encodings:\+ raw, copyrect, rre, hextile, tight, tight\+PNG, ZRLE, JPEG, Zlib, H.\+264
\item Supports scaling, clipping and resizing the desktop
\item Supports back \& forward mouse buttons
\item Local cursor rendering
\item Clipboard copy/\+paste with full Unicode support
\item Translations
\item Touch gestures for emulating common mouse actions
\item Licensed mainly under the \href{http://www.mozilla.org/MPL/2.0/}{\texttt{MPL 2.\+0}}, see \href{LICENSE.txt}{\texttt{the license document}} for details
\end{DoxyItemize}

\doxysubsubsection*{Server requirements}

no\+VNC follows the standard VNC protocol, but unlike other VNC clients it does require Web\+Sockets support. Many servers include support (e.\+g. \href{http://libvncserver.sourceforge.net/}{\texttt{x11vnc/\+libvncserver}}, \href{http://www.qemu.org/}{\texttt{QEMU}}, and \href{http://www.smartlab.at/mobilevnc/}{\texttt{Mobile\+VNC}}), but for the others you need to use a Web\+Sockets to TCP socket proxy. no\+VNC has a sister project \href{https://github.com/novnc/websockify}{\texttt{websockify}} that provides a simple such proxy.

\doxysubsubsection*{Quick start}


\begin{DoxyItemize}
\item Use the {\ttfamily novnc\+\_\+proxy} script to automatically download and start websockify, which includes a mini-\/webserver and the Web\+Sockets proxy. The {\ttfamily -\/-\/vnc} option is used to specify the location of a running VNC server:\+

{\ttfamily ./\+utils/\+novnc\+\_\+proxy -\/-\/vnc localhost:\+5901}
\item If you don\textquotesingle{}t need to expose the web server to public internet, you can bind to localhost:\+

{\ttfamily ./\+utils/\+novnc\+\_\+proxy -\/-\/vnc localhost:\+5901 -\/-\/listen localhost:\+6081}
\item Point your browser to the cut-\/and-\/paste URL that is output by the {\ttfamily novnc\+\_\+proxy} script. Hit the Connect button, enter a password if the VNC server has one configured, and enjoy!
\end{DoxyItemize}

\doxysubsubsection*{Installation from snap package}

Running the command below will install the latest release of no\+VNC from snap:\+

{\ttfamily sudo snap install novnc}

\doxysubsubsubsection*{Running no\+VNC from snap directly}

You can run the snap package installed novnc directly with, for example:\+

{\ttfamily novnc -\/-\/listen 6081 -\/-\/vnc localhost:\+5901 \# /\+snap/\+bin/\+novnc if /\+snap/\+bin is not in your PATH}

If you want to use certificate files, due to standard snap confinement restrictions you need to have them in the /\+home/\+\texorpdfstring{$<$}{<}user\texorpdfstring{$>$}{>}/\+snap/\+novnc/\+current/\+ directory. If your username is jsmith an example command would be:\+

{\ttfamily novnc -\/-\/listen 8443 -\/-\/cert \texorpdfstring{$\sim$}{\string~}jsmith/\+snap/\+novnc/\+current/\+self.crt -\/-\/key \texorpdfstring{$\sim$}{\string~}jsmith/\+snap/\+novnc/\+current/\+self.key -\/-\/vnc ubuntu.\+example.\+com:\+5901}

\doxysubsubsubsection*{Running no\+VNC from snap as a service (daemon)}

The snap package also has the capability to run a \textquotesingle{}novnc\textquotesingle{} service which can be configured to listen on multiple ports connecting to multiple VNC servers (effectively a service running multiple instances of novnc). Instructions (with example values):\+

List current services (out-\/of-\/box this will be blank):\+


\begin{DoxyCode}{0}
\DoxyCodeLine{sudo\ snap\ get\ novnc\ services}
\DoxyCodeLine{Key\ \ \ \ \ \ \ \ \ \ \ \ \ Value}
\DoxyCodeLine{services.n6080\ \ \{...\}}
\DoxyCodeLine{services.n6081\ \ \{...\}}

\end{DoxyCode}


Create a new service that listens on port 6082 and connects to the VNC server running on port 5902 on localhost:\+

{\ttfamily sudo snap set novnc services.\+n6082.\+listen=6082 services.\+n6082.\+vnc=localhost:\+5902}

(Any services you define with \textquotesingle{}snap set\textquotesingle{} will be automatically started) Note that the name of the service, \textquotesingle{}n6082\textquotesingle{} in this example, can be anything as long as it doesn\textquotesingle{}t start with a number or contain spaces/\+special characters.

View the configuration of the service just created:\+


\begin{DoxyCode}{0}
\DoxyCodeLine{sudo\ snap\ get\ novnc\ services.n6082}
\DoxyCodeLine{Key\ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ Value}
\DoxyCodeLine{services.n6082.listen\ \ 6082}
\DoxyCodeLine{services.n6082.vnc\ \ \ \ \ localhost:5902}

\end{DoxyCode}


Disable a service (note that because of a limitation in snap it\textquotesingle{}s currently not possible to unset config variables, setting them to blank values is the way to disable a service):\+

{\ttfamily sudo snap set novnc services.\+n6082.\+listen=\textquotesingle{}\textquotesingle{} services.\+n6082.\+vnc=\textquotesingle{}\textquotesingle{}}

(Any services you set to blank with \textquotesingle{}snap set\textquotesingle{} like this will be automatically stopped)

Verify that the service is disabled (blank values):\+


\begin{DoxyCode}{0}
\DoxyCodeLine{sudo\ snap\ get\ novnc\ services.n6082}
\DoxyCodeLine{Key\ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ Value}
\DoxyCodeLine{services.n6082.listen\ \ }
\DoxyCodeLine{services.n6082.vnc}

\end{DoxyCode}
