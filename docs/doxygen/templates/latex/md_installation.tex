To install Tiled\+Viz you will need to first get the \href{https://github.com/mmancip/TiledViz/releases}{\texttt{latest release}} available on github. \hypertarget{md_installation_autotoc_md76}{}\doxysubsection{\texorpdfstring{Preparing the environment}{Preparing the environment}}\label{md_installation_autotoc_md76}
For the host part, named {\bfseries{Tiled\+Viz Secure}}, you need to install:\+


\begin{DoxyItemize}
\item {\ttfamily python3}
\item {\ttfamily pip3}, usually provided by the {\ttfamily python3-\/pip} package
\item {\ttfamily libcap-\/dev}
\item {\ttfamily docker.\+io}
\item {\ttfamily docker-\/buildx}
\end{DoxyItemize}

{\itshape Please note that name may differ depending on your OS}\hypertarget{md_installation_autotoc_md77}{}\doxysubsubsection{\texorpdfstring{1. Docker rights}{1. Docker rights}}\label{md_installation_autotoc_md77}
You must first install Docker. Required Docker version:\+ 
\begin{DoxyCode}{0}
\DoxyCodeLine{17.03\ or\ newer}

\end{DoxyCode}
 You must be in the {\ttfamily docker} group to be able to launch Docker containers. 
\begin{DoxyCode}{0}
\DoxyCodeLine{sudo\ usermod\ -\/aG\ docker\ \$USER}

\end{DoxyCode}
 After adding your user to the {\ttfamily docker} group, {\bfseries{log out and log back in}}. Then check with:\+ 
\begin{DoxyCode}{0}
\DoxyCodeLine{id}

\end{DoxyCode}
 {\itshape No Tiled\+Viz containers are executed with root users for security reasons.}\hypertarget{md_installation_autotoc_md78}{}\doxysubsubsection{\texorpdfstring{2. Postgre\+SQL environment}{2. Postgre\+SQL environment}}\label{md_installation_autotoc_md78}
The Postgre\+SQL service is downloaded from Docker\+Hub with an Alpine system.

If you need several {\ttfamily postgres-\/alpine} Docker containers running, you can change the Postgre\+SQL port in {\ttfamily ./\+env\+Tiled\+Viz} before installation.

The {\ttfamily ./\+env\+Tiled\+Viz} file is private because it stores the Postgre\+SQL password for the Postgre\+SQL service.\hypertarget{md_installation_autotoc_md79}{}\doxysubsubsection{\texorpdfstring{3.
