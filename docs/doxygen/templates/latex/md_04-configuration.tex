\doxysubsubsection*{Default conﬁguration}

A default conﬁguration is loaded by Tiled\+Viz from the {\ttfamily config\+\_\+default.\+js} ﬁle. It contains the following parameters \texorpdfstring{$\ast$}{*} Colors:\+ for the diﬀerent stickers (for ﬁlters and tags), and markers of state (selected tile, tile to be zoomed, …) \texorpdfstring{$\ast$}{*} Tile conﬁguration:\+ how to use the parameters contained in {\ttfamily tiles.\+js} \texorpdfstring{$\ast$}{*} Behavioural constants:\+ number of tiles, of columns, should they be ﬁxed, spaces between tiles, …

\doxysubsubsection*{Custom conﬁguration}

In order to specify custom parameters and to enhance the user experience, it is possible to add in the Case folder a copy of {\ttfamily config\+\_\+default.\+js} (to be named {\ttfamily config.\+js}). It is not mandatory to add in this custom ﬁle all the parameters from the default conﬁguration ﬁle, but one has to be cautious of the syntax when writing those custom parameters.
