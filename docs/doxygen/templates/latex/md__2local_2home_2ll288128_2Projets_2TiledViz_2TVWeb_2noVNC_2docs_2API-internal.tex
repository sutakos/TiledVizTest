The no\+VNC client is composed of several internal modules that handle rendering, input, networking, etc. Each of the modules is designed to be cross-\/browser and independent from each other.

Note however that the API of these modules is not guaranteed to be stable, and this documentation is not maintained as well as the official external API.

\doxysection*{1.\+1 Module list}


\begin{DoxyItemize}
\item {\bfseries{\doxylink{classKeyboard}{Keyboard}}} (core/\+input/\+keyboard.\+js):\+ \doxylink{classKeyboard}{Keyboard} input event handler with non-\/\+US keyboard support. Translates key\+Down and key\+Up events to X11 keysym values.
\item {\bfseries{\doxylink{classDisplay}{Display}}} (core/\+display.\+js):\+ Efficient 2D rendering abstraction layered on the HTML5 canvas element.
\item {\bfseries{\doxylink{classWebsock}{Websock}}} (core/\+websock.\+js):\+ \doxylink{classWebsock}{Websock} client from websockify with transparent binary data support. \href{https://github.com/novnc/websockify-js/wiki/websock.js}{\texttt{Websock API}} wiki page.
\end{DoxyItemize}

\doxysection*{1.\+2 Callbacks}

For the Mouse, \doxylink{classKeyboard}{Keyboard} and \doxylink{classDisplay}{Display} objects the callback functions are assigned to configuration attributes, just as for the \doxylink{classRFB}{RFB} object. The Web\+Sock module has a method named \textquotesingle{}on\textquotesingle{} that takes two parameters:\+ the callback event name, and the callback function.
